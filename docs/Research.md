## 2. 予測アーキテクチャと統計・機械学習・深層学習モデル

### 2.1 頻度論的・統計モデル：多項ロジットモデルと Benter の市場混合モデル

競馬予測における統計的モデリングの標準的数理基盤は、ランダム効用理論に基づく条件付きロジットモデル（多項ロジット回帰: Multinomial Logit Model, MNL）である。

あるレース $r$ において出走馬 $i \in \{1, 2, \dots, N_r\}$ が獲得する潜在的効用（走破能力）を


$$U_{r,i} = \beta^{T} \mathbf{x}_{r,i} + \epsilon_{r,i}$$

と仮定する。誤差項 $\epsilon_{r,i}$ が互いに独立同分布のガンベル分布（極値分布）に従う場合、馬 $i$ が1着となる確率は以下のソフトマックス関数で導出される。


$$P(Y_{r,i} = 1 \mid \mathbf{X}_r) = \frac{\exp(\beta^{T} \mathbf{x}_{r,i})}{\sum_{j=1}^{N_r} \exp(\beta^{T} \mathbf{x}_{r,j})}$$

Bill Benter (1994, 2008) は、このモデルから得られる純粋な基礎予測確率 $P_{\text{model}}(i)$ 単体では市場の集約情報（オッズに含まれる集合知）に劣ることを示し、市場オッズから控除率を補正したインプライド勝率 $P_{\text{market}}(i)$ との対数オッズ空間における線形結合モデル（混合モデル）を提唱した。


$$\log \left( \frac{\tilde{P}(i)}{1 - \tilde{P}(i)} \right)
= \alpha_0
+ \alpha_1 \log \left( \frac{P_{\text{model}}(i)}{1 - P_{\text{model}}(i)} \right)
+ \alpha_2 \log \left( \frac{P_{\text{market}}(i)}{1 - P_{\text{market}}(i)} \right)$$

事前オッズのみを利用する場合、確定前日の前日オッズまたは朝段階オッズから導出した $P_{\text{market}}$ を特徴量またはアンサンブルの結合対象とする。市場オッズが過剰に人気馬を支持するバイアス（Favorite-Longshot Bias）を補正しつつ、モデルが検出した「過小評価された穴馬の真の勝率」を抽出する。

### 2.2 勾配ブースティング決定木（GBDT）とランキング学習（Learning to Rank）

テーブルデータにおける最高精度のベースラインとなる GBDT において、2値分類（勝つか否か）を直接目的関数に置くことは不適切である。競馬は「1頭の勝者と多数の敗者」という極端な不均衡データであり、かつ「同一レース内での順位付け」が本質であるため、情報検索で用いられるランキング学習（LTR）アルゴリズムを採用する。

- **Pointwise アプローチ**：回帰（走破タイム・スピード指数の予測）または2値クロスエントロピー損失。レース全体の文脈（他馬との相対差）が考慮されない欠点がある。
- **Pairwise アプローチ（LambdaMART / LightGBM `lambdarank`）**：レース内の任意の馬のペア $(i, j)$ において、$i$ が $j$ よりも先着する確率を最適化する。NDCG の変動幅 $|\Delta \text{NDCG}|$ を勾配の重み（$\lambda$-gradient）として利用し、上位着順の精度を重点的に引き上げる。


$$\lambda_{ij} = \frac{-\sigma}{1 + \exp(\sigma (s_i - s_j))} \left| \Delta \text{NDCG}_{ij} \right|$$

- **Listwise アプローチ（ListNet / CatBoost YetiRank）**：レース出走馬全体の順位リスト全体の確率分布（Top-1 確率または Plackett-Luce モデル）に対するクロスエントロピー損失を最小化する。

#### LightGBM における LambdaRank 実装構成例

```python
import lightgbm as lgb

# 目的変数は着順に応じた関連度スコア
# (Relevance: 1着=5, 2着=4, 3着=3, 4着=2, 5着=1, 6着以下=0)
train_data = lgb.Dataset(
    X_train,
    label=y_train_relevance,
    group=group_train,  # 各レースの出走頭数のリスト [16, 14, 18, 12, ...]
)

params = {
    "objective": "lambdarank",
    "metric": "ndcg",
    "ndcg_eval_at": [1, 2, 3],
    "learning_rate": 0.03,
    "num_leaves": 63,
    "min_data_in_leaf": 50,
    "feature_fraction": 0.8,
    "bagging_fraction": 0.8,
    "bagging_freq": 1,
    "random_state": 42,
}
model = lgb.train(params, train_data, num_boost_round=1500)
```

### 2.3 Transformer アーキテクチャの応用

自然言語処理で成功を収めた Transformer は、競馬予測において極めて強力な2つのモデリングを可能にする。

#### (1) Race-Horse Temporal Transformer（時系列レース履歴エンコーダ）

競走馬のキャリアは、過去 $T$ 走の系列データ $[R_{t-1}, R_{t-2}, \dots, R_{t-T}]$ として表現できる。各レース $R_k$ は、コース、距離、馬場状態、走破タイム、斤量、通過順位、着差などのベクトル特徴を持つ。従来の集約統計量（平均値や最大値）では失われていた「休養明けのパフォーマンス変化」「距離短縮・延長時の反応」「急激な成長曲線・衰退傾向」を、Temporal Multi-Head Self-Attention 機構により動的にエンコードする。


$$\mathbf{h}_{\text{history}} = \text{TransformerEncoder}\big([\,e(\mathbf{x}_{t-1}) + p_1,\; e(\mathbf{x}_{t-2}) + p_2,\; \dots,\; e(\mathbf{x}_{t-T}) + p_T\,]\big)$$

#### (2) Intra-Race Cross-Horse Attention（同一レース内相互作用モデリング）

ある馬が勝てるかどうかは、単にその馬の絶対能力だけでなく、「同走馬にどれだけ強力な逃げ馬がいるか（ハイペースの発生）」「他馬との相対的なスピード指数差」「展開上のポジショニング競合」に依存する。出走頭数を $N$、各馬の特徴量ベクトルを $\mathbf{z}_i \in \mathbb{R}^d$ としたとき、出走馬集合全体をシーケンスとみなし、Self-Attention によって全出走馬間の相対的相互作用を捉える。


$$\mathbf{Z}_{\text{race}} = [\mathbf{z}_1, \mathbf{z}_2, \dots, \mathbf{z}_N] \in \mathbb{R}^{N \times d}$$


$$\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\!\left(\frac{\mathbf{Q}\mathbf{K}^{T}}{\sqrt{d_k}} + \mathbf{M}\right)\mathbf{V},
\quad
\mathbf{Q} = \mathbf{Z}_{\text{race}}\mathbf{W}_Q,\;
\mathbf{K} = \mathbf{Z}_{\text{race}}\mathbf{W}_K,\;
\mathbf{V} = \mathbf{Z}_{\text{race}}\mathbf{W}_V$$

ここで $\mathbf{M}$ は出走頭数不足時のパディングマスクである。出力された表現ベクトルに Softmax を通すことで、レース内全頭の正規化された勝率分布を直接出力する。

### 2.4 グラフニューラルネットワーク（GNN）による関係構造の埋め込み

競馬におけるドメイン知識の最重要要素である「血統（Pedigree）」および「関係者（騎手・調教師・生産者・馬主）」は、本質的に巨大なグラフ構造を形成している。

| グラフ対象 | ノード定義 | エッジ定義 | 推奨 GNN 手法 |
|---|---|---|---|
| 多世代血統グラフ (Pedigree Graph) | 競走馬ノード（数万〜数十万頭） | 父（Sire）、母（Dam）、母の父（BMS）の有向リンク | **GAT / GraphSAGE**：注意機構により、どの祖先の特徴量（適性・遺伝力）が現在馬に寄与しているかを重み付け集約 |
| 競馬エコシステム異種グラフ (Heterogeneous Graph) | 馬、騎手、調教師、馬主、生産牧場（異種ノード） | 「騎乗した」「管理する」「所有する」「生産した」関係 | **HGT / RGCN**：関係タイプごとの重み行列を持ち、名門厩舎 × 特定騎手の黄金コンビ等の潜在シナジーを埋め込みベクトル化 |
| 直接対決グラフ (Bout Graph) | 競走馬ノード | 過去レースでの先着関係（重み：着差、斤量差） | **GCN + PageRank 派生モデル**：レース間を跨ぐグローバルな絶対能力レーティング（TrueSkill / Elo のグラフ拡張）の算出 |

**実装アーキテクチャ**：PyTorch Geometric（PyG）または DGL を用いて事前学習（教師なしグラフ埋め込み、または着順予測をリンク予測タスクとして解く）を行い、各馬・騎手・調教師の 32〜64 次元の潜在埋め込みベクトル $\mathbf{v}_{\text{pedigree}}, \mathbf{v}_{\text{human}}$ を生成。これらを GBDT または Transformer の入力層に結合（Concatenate）するハイブリッド構成が、最も高い予測性能と計算効率を両立する。

### 2.5 深層強化学習（DRL）による動的ベッティング戦略

従来の2段階アプローチ（勝率予測 → ケリー基準による投資配分）に対し、予測誤差や市場のテイクアウトレートを考慮しながらポートフォリオ収益の幾何平均成長率（対数資産残高）を直接最大化するエンドツーエンドの強化学習環境を構築する。

- **環境（Environment）**：時系列順に整列された各レース。前日段階の特徴量および事前オッズベクトル $\mathbf{O}_r \in \mathbb{R}^K$（$K$ は購入対象券種）。
- **状態空間（State $s_t$）**：モデル予測確率分布、事前オッズ、現在の総資金残高 $B_t$、直近 $M$ レースのドローダウン状況。
- **行動空間（Action $a_t$）**：各馬券への資金配分比率ベクトル $\mathbf{w}_t \in [0,1]^K,\; \sum_k w_{t,k} \le 1$（連続行動空間）。購入を見送る（$w_{t,k} = 0$）選択も含む。
- **報酬関数（Reward $r_t$）**：破産リスクを抑制し幾何収益率を最大化するため、対数効用報酬を採用する。


$$r_t = \log\!\left( \frac{B_{t+1}}{B_t} \right) - \lambda \cdot \text{VariancePenalty}$$

- **アルゴリズム**：連続行動空間に適した **PPO (Proximal Policy Optimization)** または **SAC (Soft Actor-Critic)** を採用し、資金管理ポリシーを方策勾配法で学習する。

## 3. 実装のための特徴量エンジニアリング体系

> 前提：数十万〜数百万レコード。リアルタイム情報（パドック、直前オッズ、直前馬体重）を排し、事前確定情報のみでモデルを構築するため、過去履歴の集計・正規化・相対化による特徴量生成がシステムの成否を分ける。

### 3.1 包括的特徴量カタログ

| 大分類 | 特徴量名称 | 数理定義・算出アルゴリズム | 目的・効果 |
|---|---|---|---|
| **能力・スピード指標**<br>(Speed & Pace) | 補正走破タイム指数 (Speed Index) | $SI = (\text{基準タイム} - \text{走破タイム}) \times \alpha + (\text{斤量} - 55) \times \beta + \text{馬場差補正} + 80$ | コース・距離・馬場状態の差異を標準化した絶対能力値 |
| | 前後半ラップ落差 (Pace Balance) | $PB = \text{前半3Fタイム} - \text{後半3Fタイム}$ | 先行力と終いの脚力のバランス、展開適性の判定 |

### 3.2 同一レース内相対化（Race-level Standardizing & Softmax Normalization）

絶対的なスピード指数や斤量は、レース全体のメンバーレベルによってその価値が異なる。そのため、レース単位グループ $\mathcal{G}_r$ における z-score 正規化および Softmax 相対化特徴量を必ず生成する。


$$z_{r,i}^{\text{norm}} = \frac{x_{r,i} - \mu_r}{\sigma_r + \epsilon},
\quad
\text{RankRatio}_{r,i} = \frac{\text{Rank}(x_{r,i})}{N_r},
\quad
\text{SoftmaxScore}_{r,i} = \frac{\exp(x_{r,i} / \tau)}{\sum_{j=1}^{N_r} \exp(x_{r,j} / \tau)}$$

### 3.3 ターゲットエンコーディングと時系列リーク防止設計

高カーディナリティのカテゴリ変数（騎手 ID、調教師 ID、種牡馬 ID 等）に Target Encoding を適用する際、未来の情報を過去の学習に含めてしまう**時間軸リーク（Look-ahead Leakage）**は、バックテストの過大評価を引き起こす最大の要因である。

**厳格な Rolling-Time-Series Target Encoding の実装規則：**


$$\hat{S}_{\text{jockey}}(t) = \frac{\sum_{\tau < t,\; \tau \ge t - W} Y_{\tau, \text{jockey}} + m \cdot \bar{Y}_{\text{prior}}}{\sum_{\tau < t,\; \tau \ge t - W} 1 + m}$$

ここで $W$ は過去ウィンドウ幅（例：730 日）、$m$ はスムージングパラメータ（事前確率の重み）である。時点 $t$ のレースの特徴量を生成する際には、時点 $t$ 以前に確定したレース結果のみを集計し、**当日の同騎手の他レース結果も絶対に除外する**。

## 4. ベッティング戦略と数理ポートフォリオ最適化

### 4.1 ケリー基準（Kelly Criterion）とその数理的拡張

予測モデルによって各事象（単勝、複勝、馬連、3連単等）の真の生起確率 $p_i$ が得られ、対応する事前オッズ（オッズ倍率）を $b_i + 1$（純利益倍率 $b_i$）とするとき、期待値


$$E_i = p_i (b_i + 1) - 1 = p_i b_i - (1 - p_i)$$

が正（$E_i > 0$）の馬券のみが投資対象となる。

#### (1) 単一ベットにおけるフルケリーとハーフケリー

対数資産の期待成長率を最大化する最適投資比率 $f^{*}$ は以下のケリーの公式で与えられる。


$$f^{*} = \frac{p \cdot b - q}{b} = \frac{p(b+1) - 1}{b} = \frac{E}{b} \qquad (q = 1 - p)$$

実際の競馬予測では推定確率 $p$ のモデル誤差（不確実性）が存在するため、フルケリーをそのまま運用するとドローダウンが過大となり破産確率が上昇する。実務上はフラクショナル・ケリー、特に $c = 0.25 \sim 0.5$ としたハーフ・ケリーまたはクォーター・ケリーを適用する。


$$f_{\text{actual}} = c \cdot f^{*} \qquad (0 < c \le 0.5)$$

#### (2) 複数馬券への同時分散ケリー最適化（Multi-Bet Simultaneous Kelly）

同一レース内で複数の買い目（例：単勝複数点、または馬連フォーメーション）に同時に賭ける場合、各買い目は互いに排他的（相互に相関）である。$K$ 個の買い目に対する投資比率ベクトル $\mathbf{f} = [f_1, \dots, f_K]^{T}$ の最適化問題は、以下の凸最適化問題として定式化される。


$$\max_{\mathbf{f}} \;\mathbb{E}\big[\log(1 + \mathbf{f}^{T}\mathbf{R})\big]
= \sum_{s=1}^{S} p_s \log\!\left( 1 + \sum_{k=1}^{K} f_k R_{k,s} \right)
\quad \text{s.t.} \quad \sum_{k=1}^{K} f_k \le 1,\; f_k \ge 0$$

ここで $s$ はレースの排他的な結末シナリオ（どの馬が勝つか、またはどの組み合わせが入線するか）、$p_s$ はその生起確率、$R_{k,s}$ はシナリオ $s$ における馬券 $k$ の純利益率（的中時は $b_k$、不的中時は $-1$）である。目的関数が狭義凹関数であるため、SLSQP や内点法（Interior Point Method）を用いて大域的最適解を高速に算出可能である。

### 4.2 混合整数計画法（MIP）による馬券ポートフォリオ構築

実際の馬券購入では、1点あたりの最低購入単位（100 円単位）という離散制約が存在する。全利用可能資金を $B$、各買い目 $k$ への購入点数を整数変数 $n_k \in \mathbb{Z}_{\ge 0}$、1点あたりの賭け金を $u = 100$ 円とするとき、期待対数収益のテイラー展開に基づく平均・分散近似、またはダウンサイドリスク制約付きの混合整数二次計画問題（MIQP）を解く。


$$\max_{\{n_k\}} \;\sum_{k=1}^{K} n_k \cdot u \cdot \mathbb{E}[R_k]
- \frac{\lambda}{2B} \sum_{j=1}^{K} \sum_{k=1}^{K} n_j n_k u^2 \,\text{Cov}(R_j, R_k)$$


$$\text{s.t.}\quad \sum_{k=1}^{K} n_k \cdot u \le B \cdot f_{\max},
\qquad n_k \in \{0, 1, 2, \dots, N_{\max}\}$$

### 4.3 パリミュチュエル方式の控除率を打破する市場の非効率性

JRA のパリミュチュエル方式において、控除率 $T$（20% 〜 27.5%）を上回る期待値（$E > 0$）を獲得するためには、市場の価格形成バイアスを狙い撃つ必要がある。

- **Favorite-Longshot Bias（本命・穴馬バイアス）**：一般投票者は一攫千金を狙って極端な大穴馬を過剰購入し、勝率の高い1〜2番人気馬を過小評価する傾向がある。単勝・複勝においてはこの歪みにより、上位人気馬の一部で控除率補正後の期待値が 1.0 を超えるポイントが出現する。
- **合成オッズと多連勝単式（3連単・馬単）の非効率性**：3連単（最大 4,896 通り）などの複雑な券種では、人間の計算能力の限界により、特定の組み合わせ（例：人気馬2頭 + 中穴馬1頭）の配当が、各馬の真の能力独立確率から計算される確率に対して著しく乖離した高オッズのまま放置される「価格形成の歪み」が構造的に多発する。

## 5. 実装ロードマップとエンドツーエンド・パイプライン設計

### 5.1 システム全体構成図

数十万〜数百万行のデータを高速に処理し、前日データのみから予測およびポートフォリオ最適化を行うシステムの全体アーキテクチャを以下に示す。

```text
【システムデータフロー】

[過去生データ DB: レース/馬/騎手/調教師/血統 (10^6 records)]
        │  (Time-series Walk-Forward Pipeline)
        ▼
[特徴量生成基盤: Polars / DuckDB]
        → 補正タイム / Rolling EMA / Target Encoding
        │
        ▼
[深層埋め込み層: PyG / PyTorch]
        → 多世代血統 GAT + キャリア履歴 Transformer
        │
        ▼
[予測エンジン (アンサンブル)]
        → LightGBM LambdaRank + FT-Transformer + Benter Logit
        │  各馬の真の勝率・入着率推定ベクトル p_pred
        ▼
[オッズ照合・歪み検出器]  ← 事前発表オッズ（前日 / 朝オッズ）
        │  全券種期待値マトリクス  E_k = p_k × Odds_k − 1
        ▼
[数理ポートフォリオ最適化]
        → 修正マルチケリー + MIP 整数計画（100 円単位）
        │
        ▼
[確定投票指示ポートフォリオ出力]
```

### 5.2 バックテスト設計：時系列ウォークフォワード検証（Walk-Forward Validation）

通常の K-Fold クロスバリデーションは、未来のデータを過去の予測に用いるため**絶対に使用してはならない**。競馬データに対しては、固定幅ローリングまたは累積拡張ウィンドウ（Expanding Window）による Walk-Forward 検証を適用する。

- **学習期間（Train Window）**：過去5年間（例：2015 年〜2019 年、約 180,000 出走レコード）
- **検証・チューニング期間（Validation Window）**：直後6ヶ月間（ハイパーパラメータ・オッズ結合係数の最適化）
- **テスト期間（Out-of-Sample Test）**：続く6ヶ月間（完全未使用データでの純粋回収率・シャープレシオ評価）
- 上記ウィンドウを6ヶ月ずつ前進（Roll）させ、2020 年〜2024 年の全期間にわたりバックテストを実施

### 5.3 評価指標体系

モデルの評価は、機械学習指標（的中率・対数損失）と財務的投資指標（回収率・リスク指標）の双方から多面的に行う。

| 指標分類 | 指標名称 | 数理定義 | 目標値・判定基準 |
|---|---|---|---|
| **ランキング・統計指標** | NDCG@1, @3 | $\text{NDCG}@K = \dfrac{\text{DCG}@K}{\text{IDCG}@K},\;\;\text{DCG}@K = \sum_{i=1}^{K} \dfrac{2^{\text{rel}_i} - 1}{\log_2(i+1)}$ | NDCG@1 > 0.82（ベースライン対比 +0.05 以上） |
| | キャリブレーション損失 (Brier Score) | $\text{BS} = \frac{1}{N}\sum_{i=1}^{N}(p_i - y_i)^2$ | 確率の歪みの最小化（過信・過小評価の排除） |
| **投資・財務指標** | 投資回収率 (ROI / 回収率) | $\text{ROI} = \dfrac{\sum \text{払戻金}}{\sum \text{総投資額}} \times 100\,(\%)$ | 控除率（75%〜80%）を上回り、108.0%〜115.0% の安定達成 |
| | シャープレシオ (Sharpe Ratio) | $\text{SR} = \dfrac{\mathbb{E}[R_{\text{daily}}] - R_f}{\sigma(R_{\text{daily}})}$ | 日次ベースで SR > 1.8（年率換算） |
| | 最大ドローダウン (Max Drawdown) | $\text{MDD} = \max_{t}\left( \dfrac{\max_{\tau \le t} B_\tau - B_t}{\max_{\tau \le t} B_\tau} \right)$ | 運用資産ベースで MDD < 25% の維持 |

## 6. 課題・リスク管理・今後の展望

### 6.1 小規模データ問題とラベルの不均衡への対処

中央競馬は年間約 3,400 レース（約 50,000 出走レコード）であり、機械学習としては中規模である。深層学習モデル（Transformer や GNN）の過学習を防ぐため、以下の正則化・データ拡張戦略を採用する。

- 地方競馬（NAR：年間約 30,000 レース）の統合による事前学習（Pre-training）と、JRA データへのファインチューニング（Transfer Learning）
- 特徴量の Dropout（TabNet / FT-Transformer の Feature Dropout：15%〜30%）
- 同一レース内の出走順序のシャッフル（順序不変性の保証）

### 6.2 オッズ変動と市場インパクトリスク（Market Slippage）

リアルタイムデータを取得せず前日段階・事前オッズに基づいてベットする場合、締切直前の大口投票による「オッズの下落（Slippage）」が最大のリスク要因となる。

**オッズ乖離リスクの防御策：**

- **安全マージン（Safety Margin）の導入**：事前オッズにおける期待値閾値を $E \ge 1.15 \sim 1.25$（15% 以上の安全余裕）に設定し、直前のオッズ低下を吸収する。
- **投票ボリューム制約**：自己の投入資金が総プール規模（売上票数）に与えるオッズ押し下げ影響を推定し、各馬券のプール総額の $0.5\% \sim 1.0\%$ を上限投資額とする。

### 6.3 将来技術の展望：量子コンピューティングと大規模基盤モデル

- **量子アニーリング（QA）による組合せ最適化**：3連単全通り（最大 4,896 通り）× 複数レースにわたる膨大なポートフォリオ最適化問題に対し、QUBO（二次無制約二値最適化）形式に落とし込み、量子アニーラを用いてリアルタイムに大域的最適解を導出するアプローチ。
- **マルチモーダル競馬基盤モデル（Equine Foundation Model）**：競走馬の血統、過去の全走行軌跡時系列データ、テキストデータ（関係者コメントやレース短評）を統合した自己教師あり学習済み基盤モデルの構築。
