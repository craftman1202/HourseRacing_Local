1. エグゼクティブサマリー

主要な発見

  • 適切なデータサイエンス手法の適用により、回収率100%超えは実現可能
  • Bill Benterの事例では年間約10億ドルの収益を達成（香港競馬）
  • アンサンブル学習（XGBoost、LightGBM）が最も高い予測精度を達成
  • ケリー基準による資金配分最適化が長期的な資本成長に不可欠
  • 適切な前処理（標準化・相対化）だけで回収率が2倍に向上した事例あり

競馬予測におけるデータサイエンスの活用は、単なる「当たる・当たらない」の予測を超えて、期待値に基づく合理的な投資判断として成熟しつつあります。本報告書では、頻度論的統計、ベイズ統計、機械学習、ディープラーニング、数理最適化など、多角的なアプローチを体系的に調査し、実践可能な戦略を提案します。

重要な洞察

競馬AIで本当に重視すべきデータは全体の約4%（期待値が1を超える馬券）に過ぎません。大多数のデータで予測精度を改善しても回収率には直接影響しないため、学習時に重み付けを行うことが重要です。

2. 予測精度向上のための主要アプローチ

2.1 頻度論的アプローチ（統計モデル）

頻度論的アプローチは、大量のデータから統計的パターンを抽出し、各馬の勝率を推定する伝統的な手法です。特に多項ロジット回帰（Multinomial Logit Regression）は、Bill Benterによって香港競馬で大成功を収めたことで知られています。

Bill Benterのアプローチ

  • 100以上の変数を使用（直近のタイム、体重、騎手データ、天候、枠順など）
  • 多変量回帰分析により各馬の真の勝率を計算
  • 市場オッズと推定確率の乖離（エッジ）を特定
  • ケリー基準による最適資金配分
  • 結果：年間約10億ドルの収益

出典: Bloomberg - "The Gambler Who Cracked the Horse-Racing Code"

多項ロジット回帰の基本式：
P(馬iが勝つ) = exp(β₀ + β₁X₁ + β₂X₂ + ... + βₙXₙ) / Σⱼ exp(β₀ + β₁Xⱼ₁ + β₂Xⱼ₂ + ... + βₙXⱼₙ)

2.2 ベイズ統計的アプローチ

ベイズ統計は、事前知識（事前確率）を新しい情報（尤度）で更新し、事後確率を得る手法です。競馬では、血統データや馬場適性などの専門知識を数学的に組み込むことができます。

血統データを活用したベイズ推定

血統（種牡馬やブルードメアサイア）を「新しい情報」として扱い、レースごとに各馬の勝率を更新します。

ベイズ更新式：
P(勝つ | 血統) = P(血統 | 勝つ) × P(勝つ) / P(血統)

ベイズ因子λを用いた簡略化：
λ = P(血統 | 勝つ) / P(血統 | 負ける)
更新後の確率 = λ / (1 + (λ - 1) × 事前確率) × 事前確率

出典: walkintheforest.net - 「競馬AI：血統✖️ベイズ推定で予想確率を向上！」

Stan/Rによる能力値推定

将棋の棋士レーティングと同様に、馬と騎手の「強さ」をベイズモデルで推定する手法も有効です。事前分布に馬と騎手の力の割合を7:3と仮定し、グレード別（G1、G2、G3）に能力値を推定します。

出典: Qiita - 「競馬AIの自作と今年のレースで検証してみた」

2.3 機械学習アプローチ

機械学習、特にアンサンブル学習（Ensemble Learning）は、現在最も高い予測精度を達成している手法です。

アルゴリズム 特徴 予測精度
ランダムフォレスト 複数の決定木を組み合わせ、過学習を防ぐ 高い（各種研究で最高精度を記録）
XGBoost 勾配ブースティング、高速・高精度 非常に高い（MAE 0.000225秒）
LightGBM GPUサポート、高速学習（300秒 vs 5000秒） 非常に高い（XGBoostと同等）
CatBoost カテゴリ変数の自動処理、過学習に強い 最高（RMSE 0.000368秒）

出典: Medium - "High-Precision Prediction of Horse Racing Durations Using Ensemble Machine Learning Models"

ランキング学習（Learning to Rank）

競馬は順位予測問題として捉えることができます。LightGBMのlambdarank目的関数を使用することで、レース内の相対順位を直接学習できます。

params = {
  'objective': 'lambdarank',
  'metric': 'ndcg',
  'boosting': 'gbdt',
  'learning_rate': 0.05
}
train_data = lgb.Dataset(X, label=y, group=group)

出典: issoh.co.jp - 「競馬予想AIの特徴量一覧｜LightGBMランキング学習の実装」

重要な特徴量

機械学習モデルで効果的な特徴量は以下の通りです：

  • 馬の情報：年齢、性別、体重、体重変化、前走からの経過日数
  • 過去の成績：前走・2走前・3走前の順位、タイム、上がり3ハロン
  • 騎手・調教師：勝率、複勝率、能力値（ベイズ推定）
  • レース条件：距離、馬場状態、天候、コース（芝/ダート）、頭数
  • 枠順・馬番：特定のコースでの有利不利

出典: Qiita - 「機械学習で競馬の回収率100%超えを達成した話」

2.4 ディープラーニングアプローチ

ディープラーニングは、特に時系列データを扱う際に有効です。部分再帰型ニューラルネットワーク（RNN/LSTM）は、馬の過去の成績を時系列として捉え、次のレース結果を予測します。

部分再帰型ニューラルネットワークの活用

競馬データは時系列データと属性データの混合です。LSTMを使用することで、過去のレースパターンを記憶しながら予測精度を向上させることができます。

  • 香港競馬データ（6000+レース）で訓練精度92%を達成した事例あり
  • 過学習の問題に対処するため、より深く広いネットワーク構造を採用
  • CNNとLSTMを組み合わせることで特徴抽出と時系列パターン認識を統合

出典: Towards Data Science - "Predicting Horse Racing Results with Deep Learning"; 人工知能学会論文 - 「部分再帰型ニューラルネットワークを用いた最適な競馬の...」

注意点

ディープラーニングは小規模データでは過学習しやすく、解釈性が低いという課題があります。競馬データは一般的に小〜中規模であるため、アンサンブル学習（LightGBM/XGBoost）の方が実用的なケースが多いです。

2.5 強化学習アプローチ

強化学習は、「どの馬が勝つか」ではなく、「どういう時に馬券を買うか・買わないか」という行動方針を学習する手法です。

強化学習の課題

  • 大量のデータと試行錯誤が必要：競馬データは週1回程度しか増えないため、学習に非常に長い時間がかかる
  • 専門的な知識が必要：報酬設計、ハイパーパラメータ調整など、高度な技術が求められる
  • 実用性が不明：教師あり学習と比較して、実際に優れた結果が得られるかは不明確

出典: note.com - 「競馬AI作りは何が難しいのか」

一方で、サッカーくじ（Toto）などのスポーツベッティングでは、強化学習によるバンクロール管理（資金配分）が有効であることが示されています。競馬でも、予測モデルと組み合わせたハイブリッドアプローチが今後期待されます。

出典: Journal of Data Intelligence and AI Systems - "Reinforcement Learning-Based Bankroll Management for Football Lottery Investments"

3. ベッティング戦略と数理最適化

どれだけ予測精度が高くても、適切なベッティング戦略がなければ利益を最大化できません。数理最適化により、リスクを管理しながら長期的な資本成長を目指します。

3.1 ケリー基準（Kelly Criterion）

ケリー基準とは

ケリー基準は、長期的な資本成長率を最大化する最適なベットサイズを計算する数学的公式です。Edward O. Thorpが開発し、Bill Benterも採用しました。

ケリー基準の公式：
f* = (p × (O - 1) - (1 - p)) / (O - 1)

f*: 賭けるべき資金の割合
p: 勝つ確率（推定勝率）
O: オッズ（配当倍率）

修正ケリー基準（Generalized Kelly Criterion）

市場の非効率性と確率推定の不確実性を考慮した修正版：

f* = (P(O - 1) - (1 - P)) / (O - 1)
さらに分散を考慮した調整を加える

フルケリー vs ハーフケリー：フルケリーは破産リスクが高いため、実務ではハーフケリー（f* / 2）やクォーターケリー（f* / 4）が推奨されます。

出典: marcoseduardoelias.com - "A Quantitative Model for Horse Race Betting"

実践例：ケリー基準の適用

推定勝率（p） オッズ（O） 期待値 ケリー基準（f*）
25% 5.0倍 1.25 6.25%
20% 3.0倍 0.6 0%（賭けない）
30% 4.0倍 1.2 10%

3.2 ポートフォリオ理論の応用（シャープレシオ最大化）

現代ポートフォリオ理論（Modern Portfolio Theory）を競馬に応用し、リターンとリスクのバランスを最適化します。

最大化する目的関数（シャープレシオ）：
Maximize: E[p × ρ × f] / √(fT Σ f)

制約条件: Σfi = 1, fi ≥ 0

p: 予測勝率ベクトル
ρ: ネットリターンベクトル（オッズ - 1）
f: 各馬券への投資比率
Σ: 共分散行列（リスク）

Python実装例（scipy.optimize）

import scipy.optimize as sco

def sharpe_ratio(f, odds_matrix, pred):
  expected_return = np.dot(pred * (odds_matrix - 1), f)
  risk = np.sqrt(np.dot(f.T, np.dot(covariance_matrix, f)))
  return -expected_return / risk # 最小化問題として定式化

opts = sco.minimize(fun=sharpe_ratio, x0=x0, args=(odds_matrix, pred),
                  method="SLSQP", bounds=bounds, constraints=constraints)

3.3 整数計画による最適化

複数の馬券を組み合わせる際、どの馬が勝っても最低限の利益が出るように賭け金を最適化する手法です。Python PuLPライブラリを使用して整数計画問題として定式化します。

問題設定

  • 変数：各馬に賭ける口数（整数）
  • 目的関数：購入金額の合計を最小化
  • 制約条件：どの馬が勝っても利益 ≥ 最低利益（例：500円）
import pulp

# 変数定義
buy = pulp.LpVariable.dicts("buy", horses, lowBound=0, cat=pulp.LpInteger)

# 目的関数：購入金額の最小化
problem = pulp.LpProblem(sense=pulp.LpMinimize)
total_buy = sum(unit_cost * buy[horse] for horse in horses)
problem += total_buy

# 制約：どの馬が勝っても最低利益以上
for horse in horses:
  problem += unit_cost * buy[horse] * odds[horse] - total_buy >= min_profit

出典: yamaimo.hatenablog.jp - 「競馬に関して最適化問題を解いた話。」

4. 実践的な戦略提案

4.1 データ収集と前処理

データソース

  • netkeiba.com：最も包括的な日本競馬データベース（Web スクレイピングで取得可能）
  • JRA-VAN：公式データAPI（月額880円）、高品質でCSV形式
  • 地方競馬：各主催者の公式サイト

前処理のベストプラクティス

1. 標準化（Standardization）

各特徴量を平均0、分散1に変換することで、スケールの違いを解消します。

Z = (X - μ) / σ

k近傍法（k-NN）での検証例：標準化なし（複勝回収率46%）→ 標準化あり（複勝回収率90.8%）

出典: alphaimpact.co.jp - 「データの前処理だけで競馬は強くなる」

2. レース内相対化（Zスコア・偏差値）

機械学習モデルは各行を独立に処理するため、同じレース内の他馬との関係性を明示的に教える必要があります。

  • 走破タイムのZスコア：そのレースでの相対的な速さ
  • 上がり3ハロンのZスコア：末脚の比較
  • 位置取りのZスコア：脚質の相対的位置

推奨：「生データ」「レース平均」「レース標準偏差」「Zスコア」のすべてをセットで投入することで、レース全体の分布形状をモデルに伝える。

出典: note.com - 「競馬AI開発記 ②：特徴量設計について1」

3. ターゲットエンコーディング

騎手IDや種牡馬IDなどのカテゴリ変数を、目的変数（勝率、複勝率など）の統計値に置換します。

# 騎手IDを勝率に変換
jockey_win_rate = df.groupby('jockey_id')['win'].mean()
df['jockey_encoded'] = df['jockey_id'].map(jockey_win_rate)

4.2 モデル構築のベストプラクティス

時系列データ特有の注意点

1. 時系列クロスバリデーション

通常のランダム分割はリーク（未来の情報が訓練データに混入）を引き起こします。時系列順にデータを分割し、未来のデータで過去のデータを予測する検証を行います。

  • Train-Test Splits（単純分割）は不十分
  • Multiple Train-Test Splits（複数期間での検証）を推奨
  • ウォークフォワード検証（Walk-Forward Validation）が最も信頼性が高い

出典: watanta.hatenablog.com - 「競馬予測システムでMLOps実践~回収率140%でぬか喜びした話」

2. リーク防止

以下のような未来の情報を誤って使用しないよう注意が必要です：

  • レース後に確定するオッズを特徴量に含めてしまう
  • 馬の最終成績（引退後の情報）を含めてしまう
  • 過去の集計時に未来のデータを含めてしまう

評価指標

指標 説明 目標値
的中率 予測が当たった割合 単勝：8-10%
複勝：40%以上
回収率 （払戻金 / 投資額）× 100% 100%以上（利益が出る）
期待値 予測勝率 × オッズ 1.0以上の馬券のみ購入
シャープレシオ リスク調整後リターン 0.5以上が望ましい

重要：的中率が高くても回収率が低ければ意味がありません。回収率と期待値を最重視すべきです。

4.3 推奨されるハイブリッドアプローチ

最適な戦略の組み合わせ

  1. 予測モデル：アンサンブル学習（LightGBM + XGBoost）
    • ランキング学習（lambdarank）で順位予測
    • 複数モデルの平均や加重平均で予測精度を向上
  2. 特徴量エンジニアリング
    • 標準化 + レース内相対化（Zスコア）
    • ターゲットエンコーディング
    • 過去3レースの統計情報
  3. ベイズ更新による補正
    • 血統データや馬場適性でモデル予測を更新
  4. ベッティング戦略：修正ケリー基準
    • 期待値 ≥ 1.0 の馬券のみ選択
    • ハーフケリーまたはクォーターケリーで資金配分
  5. リスク管理
    • 1レースあたりの投資上限：総資金の5-10%
    • 損失制限（ストップロス）の設定

実装フロー例

  1. データ取得：netkeiba.comからスクレイピング（毎週更新）
  2. 前処理：標準化、相対化、ターゲットエンコーディング
  3. 学習：LightGBM（lambdarank）でモデル構築
  4. 予測：次週のレースに対して各馬の予測スコアを計算
  5. 期待値計算：予測勝率 × 予測オッズ ≥ 1.0 の馬を抽出
  6. 資金配分：ケリー基準で各馬券への投資額を決定
  7. 購入実行：オートベット（可能な場合）またはメール通知
  8. 結果記録：回収率、的中率、シャープレシオを継続的にモニタリング

5. 既存の成功事例と実績

5.1 Bill Benterの事例（香港競馬）

史上最も成功した競馬投資家

  • 収益：年間約10億ドル（累計では約10億ドル以上）
  • 手法：多項ロジット回帰 + ケリー基準
  • 変数：100以上（馬の直近タイム、体重、騎手データ、天候、枠順、調教データなど）
  • 市場：香港競馬のパリミュチュエル方式
  • エッジ：市場オッズと真の確率の乖離を特定し、裁定取引を実行

Benterのチームは、各馬の真の勝率を推定し、それが市場オッズと比較して20%なのに25%の確率があると判断した場合、エッジがあると見なして賭けを行いました。ケリー基準により、エッジの大きさと分散に応じて賭け金を決定し、破産を防ぎながら長期的な資金成長を実現しました。

出典: Bloomberg - "The Gambler Who Cracked the Horse-Racing Code"; LinkedIn Pulse - "Bill Benter's Horse Racing Model"

上記の成功事例は、特定の期間・条件下での結果です。特に短期間（1ヶ月〜1年）の検証では、偶然の要素が大きく影響します。長期的な検証（3年以上）と、複数の市場・条件での再現性が重要です。

  • オッズパーク：地方競馬・競輪・オートレース対応、無料でAI推奨馬を確認可能
  • JRA-VAN：公式データAPI、月額880円、上級者向け（自分でモデル構築）

これらのサービスの的中率は複勝で60-70%程度ですが、これは人気上位3頭のうち1頭が3着以内に入る確率であり、AI特有の成果とは言えません。重要なのは回収率であり、長期的に100%を超え続けるサービスは稀です。

出典: genai-ai.co.jp - 「AI競馬予測とは？仕組み・おすすめサービス3選」

6. 課題と限界

6.1 データの限界

小規模データ問題

  • データ量の制約：中央競馬は週に約36レース、年間約3,600レース。画像認識などと比較すると極めて少ない。
  • ディープラーニングの限界：小規模データではディープラーニングは過学習しやすく、LightGBM/XGBoostなどの木ベースモデルの方が有効。
  • ラベルの不均衡：1着は1頭のみ（他は負け）。不均衡データへの対処が必要。

6.2 市場の非効率性と控除率

パリミュチュエル方式の影響

日本競馬（中央・地方）はパリミュチュエル方式を採用しており、控除率（テラ銭）が20-30%設定されています。これは参加者全体の平均回収率が70-80%に収斂することを意味します。

  • 単勝・複勝：控除率約20%
  • 馬連・ワイド：控除率約22.5%
  • 3連単：控除率約27.5%

つまり、控除率を超えて継続的に利益を出すには、市場平均より30%以上優れた予測が必要です。

オッズの変動

予測オッズと確定オッズの乖離により、期待値が変動します。特にAI予測が普及すると、オッズの歪みが減少し、エッジが小さくなる可能性があります。

参照: note.com - 「予想オッズと確定オッズの変動率から期待値あり馬を見つける」

6.3 過学習のリスク

時系列データ特有の問題

  • 過去のパターンが未来に適用できない：競馬環境は変化します（新馬の登場、騎手の引退、コース改修など）。過去データへの過度な最適化は危険です。
  • 評価方法の不適切性：単一期間（1ヶ月など）での検証は偶然の要素が大きく、140%の回収率が単なるラッキーである可能性があります。Multiple Train-Test Splitsやウォークフォワード検証が必須です。
  • リークの危険性：未来の情報（確定オッズ、最終成績など）を誤って使用すると、実運用で全く機能しないモデルになります。

対策

  • 時系列クロスバリデーション（Time Series Cross-Validation）の徹底
  • アーリーストッピング（Early Stopping）で過学習を防ぐ
  • 正則化（L1/L2 Regularization）の適用
  • 複数モデルのアンサンブルで汎化性能を向上
  • 継続的なモデル更新（週次または月次）

7. 最適な戦略の提案

以上の調査結果を踏まえ、中央競馬および地方競馬において予測精度を向上させ、最適なベット戦略を立てるための実践的な推奨戦略を提案します。

7.1 短期戦略（3-6ヶ月）

即座に実装可能な戦略

  1. 期待値フィルタリング
    • 予測勝率 × オッズ ≥ 1.0 の馬券のみ購入
    • さらに、予測1位と2位の差が0.1以上の場合のみ購入（自信度フィルタ）
  2. ゼロファクター戦略
    • 新潟芝1000m：7枠・8枠の複勝
    • 中京芝1200m：1枠・2枠かつ出走頭数13頭以上かつ2番人気以下
    • 福島ダート1150m：出走頭数13頭以上かつ3番人気以上かつ単勝オッズ10倍以上

    出典: note.com - 「回収率100%超えの合理的な条件」

  3. 資金配分
    • 総資金の5%以内を1レースに投資
    • 期待値に応じてハーフケリーで配分

7.2 中長期戦略（6ヶ月〜2年）

本格的なAIモデル構築

  1. データ基盤の構築
    • netkeiba.comから過去5年分のデータをスクレイピング
    • 週次でデータ更新パイプラインを自動化（Jenkins, Airflowなど）
    • データバリデーション（欠損値チェック、異常値検出）を実装
  2. アンサンブルモデルの構築
    • LightGBM（lambdarank）+ XGBoost（lambdarank）
    • 2つのモデルの予測を平均または加重平均
    • 時系列クロスバリデーションで汎化性能を検証
  3. 特徴量エンジニアリング
    • 標準化 + レース内Zスコア
    • ターゲットエンコーディング（騎手、調教師、種牡馬）
    • 過去3レースの統計（平均順位、平均タイム、上がり3ハロン）
  4. ベイズ更新の統合
    • 血統データでモデル予測を補正
    • 馬場適性（芝/ダート、距離）をベイズ因子で反映
  5. ベッティング最適化
    • 修正ケリー基準で資金配分
    • シャープレシオ最大化（scipy.optimize）
    • 複数馬券の組み合わせ最適化（整数計画）
  6. 継続的なモニタリングとMLOps
    • 回収率、的中率、シャープレシオをDashboard化（Dash, Streamlit）
    • モデルドリフト検出（予測精度の低下を監視）
    • 月次でモデル再学習

7.3 リスク管理

破産リスクの回避

  • 資金配分ルール：
    • 1レースあたりの投資上限：総資金の5-10%
    • 1日あたりの投資上限：総資金の20%
    • フルケリーではなくハーフケリーまたはクォーターケリーを使用
  • ストップロス（損失制限）：
    • 月次損失が総資金の20%に達したら、投資を一時停止
    • モデルの再評価と改善を実施
  • 分散投資：
    • 単勝だけでなく、複勝、馬連、ワイドなど複数の馬券種に分散
    • 中央競馬と地方競馬の両方に投資
  • 心理的バイアスの排除：
    • 感情に流されず、モデルの推奨に従う
    • 「追い上げ」「熱くなる」を避ける

8. 結論と今後の展望

主要な結論

  1. 回収率100%超えは実現可能
    適切なデータサイエンス手法（アンサンブル学習、ベイズ統計、ケリー基準）を組み合わせることで、長期的に回収率100%を超えることは理論的・実践的に可能です。Bill Benterの事例はその証明です。
  2. 最も効果的なアプローチ
    現時点では、LightGBM/XGBoostのアンサンブル学習 + ランキング学習が最も高い予測精度を達成しています。ディープラーニングは小規模データでは過学習しやすく、実用性が限定的です。
  3. 特徴量エンジニアリングの重要性
    標準化とレース内相対化（Zスコア）だけで回収率が2倍に向上した事例があります。適切な前処理は予測モデルよりも重要な場合があります。
  4. ベッティング戦略の重要性
    どれだけ予測精度が高くても、適切な資金配分（ケリー基準）がなければ利益を最大化できません。リスク管理と組み合わせることで、長期的な資本成長を目指します。
  5. 課題と限界の認識
    控除率（20-30%）、市場の非効率性の減少、過学習のリスクなど、多くの課題があります。「確実に儲かる」システムは存在せず、継続的な改善と適応が必要です。

今後の展望

技術的進化の可能性

  • Transformer モデルの応用： 自然言語処理で成功したTransformerアーキテクチャを時系列データに適用する研究が進んでいます。競馬の過去レースをシーケンスとして扱い、Attention機構で重要なレースを自動抽出する可能性があります。
  • グラフニューラルネットワーク（GNN）： 馬、騎手、調教師の関係性をグラフとして表現し、GNNで学習する手法が研究されています。血統ネットワークとの統合も期待されます。
  • 量子コンピューティング： 組み合わせ最適化（馬券の最適購入組み合わせ）において、量子アニーリングが従来手法を超える可能性があります。
  • リアルタイムデータの統合： レース直前の馬の挙動（パドック映像の画像認識）やジョッキーの表情分析など、非構造化データの活用が進む可能性があります。
  • 説明可能AI（XAI）： SHAP値やLIMEなどの手法により、モデルの予測根拠を可視化し、ドメイン知識との融合を深めることができます。

コミュニティと知識共有

競馬データサイエンスのコミュニティは成長しており、以下のプラットフォームで知識共有が活発です：

  • Qiita, note, Zennでの技術記事投稿
  • GitHubでのオープンソースプロジェクト（例：gmalbert/horse-racing-predictions）
  • Kaggleでの競馬予測コンペティション
  • Reddit (r/algobetting, r/horseracing) での議論

最終提言

競馬予測におけるデータサイエンスは、単なる「当たる・当たらない」のギャンブルから、期待値に基づく合理的な投資判断へとパラダイムシフトを起こしつつあります。しかし、以下の点を肝に銘じる必要があります：

  • 長期的視点：短期的な成功（1ヶ月で回収率140%など）は偶然の可能性が高い。最低3年以上の継続的な検証が必要。
  • 継続的な改善：競馬環境は変化するため、モデルも継続的に更新・改善する必要がある。
  • リスク管理の徹底：どれだけ優れたモデルでも、破産リスクを完全にゼロにはできない。資金配分とストップロスは必須。
  • 学習の価値：たとえ利益が出なくても、データサイエンスの実践的スキルを磨く絶好の機会となる。

本報告書が、競馬予測におけるデータサイエンスの理解を深め、実践的な戦略構築の一助となることを願っています。
